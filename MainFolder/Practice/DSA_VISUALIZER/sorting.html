C++ — Bubble Sort 
// Bubble Sort - O(n²)
void bubbleSort(int arr[], int n) {
  for (int i = 0; i < n-1; i++) {
    for (int j = 0; j < n-i-1; j++) {
      if (arr[j] > arr[j+1]) {
        swap(arr[j], arr[j+1]);
      }
    }
  }
}

📖 How Bubble Sort Works

Bubble Sort repeatedly steps through the list, compares adjacent elements, and swaps them if they're in the wrong order. Larger elements "bubble up" to their correct position at the end.

1
Compare adjacent elements (arr[j] and arr[j+1])
2
If left > right, SWAP them (watch them lift!)
3
After each pass, largest element is fixed at the end
4
Repeat until no swaps needed

C++ — Insertion Sort 
// Insertion Sort - O(n²)
void insertionSort(int arr[], int n) {
  for (int i = 1; i < n; i++) {
    int key = arr[i];
    int j = i - 1;
    while (j >= 0 && arr[j] > key) {
      arr[j+1] = arr[j];
      j--;
    }
    arr[j+1] = key;
  }
}

📖 How Insertion Sort Works

Insertion Sort builds the final sorted array one element at a time. Like sorting playing cards in your hand — you pick a card and insert it into its correct position.

1
Pick the current element (key)
2
Shift larger elements to the right
3
Insert the key in its correct position

C++ — Selection Sort 
// Selection Sort - O(n²)
void selectionSort(int arr[], int n) {
  for (int i = 0; i < n-1; i++) {
    int minIdx = i;
    for (int j = i+1; j < n; j++) {
      if (arr[j] < arr[minIdx]) minIdx = j;
    }
    swap(arr[minIdx], arr[i]);
  }
}

📖 How Selection Sort Works

Selection Sort divides the array into sorted (left) and unsorted (right) portions. It repeatedly selects the minimum element from the unsorted portion and swaps it to the front.

1
Find the minimum element in unsorted portion
2
SWAP it with the first unsorted element
3
Expand sorted portion by one
