### 3. Streamlit Cloud se Connect Karein
Ab niche diye gaye steps follow karein:

<Steps>
{/* Reason: Order is critical for successful deployment on the cloud platform. */}
  <Step title="Sign In to Streamlit Cloud" subtitle="Requires GitHub Account">
    [share.streamlit.io](https://share.streamlit.io/) par jayein aur apne GitHub account se login karein.
  </Step>
  <Step title="Connect Repository" subtitle="Select your project">
    **"New app"** button par click karein. Phir apni GitHub repository select karein jisme aapka DSA Visualizer ka code pada hai.
  </Step>
  <Step title="Set Main File" subtitle="Usually app.py">
    "Main file path" mein apni main file ka naam likhein (e.g., `app.py`).
  </Step>
  <Step title="Deploy & Share" subtitle="Get your link">
    **"Deploy!"** par click karein. 2-3 minute mein aapki app live ho jayegi aur aapko upar browser mein ek unique link mil jayega (jaise: `dsa-visualizer.streamlit.app`).
  </Step>
</Steps>

| Requirement | Purpose |
