Searching Algorithms

Visualize how elements are found — sequentially or via binary division.

Algorithms
C++ — Linear Search 
// Linear Search  O(n)
int linearSearch(int arr[], int n, int target) {
  for (int i = 0; i < n; i++) {
    if (arr[i] == target)
      return i;   // Found
  }
  return -1;       // Not found
}

C++ — Binary Search 
// Binary Search  O(log n)
int binarySearch(int arr[], int n, int target) {
  int low = 0, high = n - 1;
  while (low <= high) {
    int mid = low + (high - low) / 2;
    if (arr[mid] == target) return mid;
    if (arr[mid] <  target) low  = mid + 1;
    else                    high = mid - 1;
  }
  return -1;
}

Explanation

Binary Search works on sorted arrays. It repeatedly halves the search interval.

1

Set low=0, high=n-1

2

Compute mid = (low+high)/2

3

If arr[mid]==target → found!

4

If target > arr[mid] → search right half
